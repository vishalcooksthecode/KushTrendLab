# KushTrendLab - Professional Video Editing & Production Agency

A modern, premium dark-theme website for a video editing and video production agency. Built with React, Tailwind CSS, and Framer Motion for smooth animations and cinematic visuals.

## 🎬 Features

### Design & UX
- **Dark Theme**: Premium black background with red and neon accents
- **Glassmorphism Effects**: Modern frosted glass UI elements
- **Smooth Animations**: Framer Motion animations throughout
- **Responsive Design**: Fully responsive for mobile and desktop
- **Modern Typography**: Poppins, Inter, and Montserrat fonts

### Sections

1. **Hero Section**
   - Cinematic heading and subheading
   - Animated background elements
   - Glowing gradients and CTA buttons
   - Statistics counters

2. **Services Section**
   - Video Editing Services (4 cards)
     - Podcast Editing: ₹2,999
     - Long Form Video: ₹2,999 (up to 10 min)
     - Short Form Video: ₹1,099
     - Birthday Reel: ₹1,099

3. **Video Shoot Services**
   - Professional shoot packages
     - Podcast Video Shoot: ₹1,499 + Charges
     - Reel Shoot: ₹500 + Charges
     - Long Form Shoot: ₹1,099 + Charges
     - Birthday Shoot: ₹1,499 + Charges

4. **Portfolio Gallery**
   - Video preview cards with hover effects

   - Project categorization

5. **Testimonials**
   - Client testimonial carousel

6. **Payment Section**

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/vishalcooksthecode/KushTrendLab.git

# Navigate to the project
cd KushTrendLab

# Install dependencies
npm install

# Start the development server
npm start
```

## 🚀 Build

```bash
npm run build
```
