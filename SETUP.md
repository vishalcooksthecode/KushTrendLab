# KushTrendLab Website

A modern, premium dark-theme website for KushTrendLab - a professional video editing and video production agency.

## Quick Start

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
